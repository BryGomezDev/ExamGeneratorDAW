PREGUNTA: ¿Cuál de las siguientes características de Gedit lo hace destacar como editor de texto?
A: Uso en Windows y entornos como GNOME.
B: Guardar y copiar texto.
C: Uso en windows.
D: Distintos usos de fuentes.
RESPUESTA: A
EXPLICACION: Gedit es el editor de texto oficial del entorno de escritorio GNOME (Linux). Su característica distintiva es la compatibilidad multiplataforma: funciona en Linux (su entorno nativo), macOS y también Windows, aunque está especialmente integrado en GNOME. Guardar, copiar o usar fuentes son funciones básicas de cualquier editor de texto y no son características diferenciadoras de Gedit.

PREGUNTA: Con cual de estos podemos editar páginas web:
A: Bloc de notas de Windows.
B: Gedit.
C: Notepad++.
D: Todas las anteriores son correctas.
RESPUESTA: D
EXPLICACION: Un archivo HTML o XML no es más que texto plano, por lo que cualquier editor de texto puede abrirlo y modificarlo. El Bloc de notas de Windows, Gedit y Notepad++ son todos capaces de editar páginas web, aunque con diferente nivel de comodidad: Notepad++ añade resaltado de sintaxis para HTML/CSS/JS, Gedit también lo soporta con plugins, y el Bloc de notas es básico pero funcional.

PREGUNTA: El formato de codificación de caracteres generalmente empleado por XML es:
A: uef-8.
B: utf-8.
C: uft-8.
D: ufe-8.
RESPUESTA: B
EXPLICACION: UTF-8 (Unicode Transformation Format, 8 bits) es la codificación estándar para XML y la web en general. Se declara en el prólogo del documento: <?xml version="1.0" encoding="UTF-8"?>. UTF-8 es compatible con ASCII para los 128 caracteres básicos y usa secuencias de 2-4 bytes para el resto del estándar Unicode. Las otras opciones (uef-8, uft-8, ufe-8) no existen; son distractores con letras transpuestas.

PREGUNTA: En XML los valores siempre deben:
A: Ser numéricos.
B: Entrecomillarse.
C: Ir entre símbolos de igual.
D: Acotarse con los símbolos "<" y ">".
RESPUESTA: B
EXPLICACION: En XML, los valores de los atributos deben ir siempre entre comillas, ya sean simples o dobles: <libro id="123"> o <libro id='123'>. Los valores numéricos dentro de elementos no requieren comillas (van entre etiquetas de apertura y cierre), pero los valores de atributos sí. El símbolo "=" separa el nombre del atributo de su valor, y "<" y ">" delimitan las etiquetas, no los valores.

PREGUNTA: Selecciona la afirmación correcta:
A: Los elementos XML no necesitan estar anidados correctamente.
B: Un documento XML puede tener múltiples elementos de raíz.
C: La estructura de los documentos XML debe ser jerárquica con un único elemento raíz.
D: No es necesario que los elementos se abran y cierren en el orden correcto.
RESPUESTA: C
EXPLICACION: Un documento XML bien formado (well-formed) tiene obligatoriamente un único elemento raíz que contiene a todos los demás. Los elementos deben estar correctamente anidados (el último en abrirse debe ser el primero en cerrarse) y todas las etiquetas deben cerrarse. Esto distingue XML de HTML, que es más permisivo con el anidado y el cierre de etiquetas.

PREGUNTA: La estructura de XML consta de:
A: Prólogo y directorio.
B: Índice y cuerpo.
C: Prólogo y cuerpo.
D: Todas las anteriores son incorrectas.
RESPUESTA: C
EXPLICACION: Un documento XML se divide en dos partes: el prólogo, que contiene la declaración XML (<?xml version="1.0" encoding="UTF-8"?>) y opcionalmente la referencia a un DTD o schema para validación; y el cuerpo, que es el contenido real del documento con el elemento raíz y toda la jerarquía de elementos anidados. No existe "directorio" ni "índice" como partes de la estructura XML.

PREGUNTA: La extensión predeterminada de los archivos del bloc de notas es:
A: .txt.
B: .doc.
C: .docx.
D: .xml.
RESPUESTA: A
EXPLICACION: El Bloc de notas de Windows guarda por defecto con extensión .txt (texto plano). Los formatos .doc y .docx son exclusivos de Microsoft Word e incluyen formato enriquecido, mientras que .txt no contiene ningún formato. Aunque el Bloc de notas puede guardar archivos con cualquier extensión (incluida .xml o .html) si se especifica, su extensión predeterminada es siempre .txt.

PREGUNTA: Los lenguajes de marcas pueden ser de:
A: Procedimiento.
B: Presentación.
C: Descriptivos.
D: Todas las anteriores son correctas.
RESPUESTA: D
EXPLICACION: Los lenguajes de marcas se clasifican en tres tipos: de procedimiento (indican cómo debe procesarse el documento, como TeX o troff), de presentación (definen el aspecto visual, como RTF o los estilos de WordprocessingML) y descriptivos o semánticos (describen qué es cada elemento sin indicar cómo mostrarlo, como HTML o XML). Los tres tipos existen y son categorías reconocidas en la teoría de lenguajes de marcas.

PREGUNTA: SGML son las siglas de:
A: Standard Generalized Markup Language.
B: Sistem Generalized Markup Language.
C: Synthesis Generalized Markup Language.
D: Es GSML no SGML.
RESPUESTA: A
EXPLICACION: SGML (Standard Generalized Markup Language) es el metalenguaje de marcas estándar ISO (ISO 8879:1986) del que derivan HTML y XML. "Standard" hace referencia a su naturaleza de estándar internacional, "Generalized" indica que es un marco genérico para definir otros lenguajes de marcas, y "Markup Language" describe su función. Las opciones B y C tienen palabras incorrectas, y la D es falsa.

PREGUNTA: ¿Cuál de las siguientes características no es comúnmente proporcionada por Notepad++?
A: Autocompletado.
B: Búsqueda y reemplazo.
C: Resaltado de sintaxis.
D: Edición de imágenes.
RESPUESTA: D
EXPLICACION: Notepad++ es un editor de texto y código fuente, no un editor de imágenes. Sus características principales incluyen resaltado de sintaxis para más de 80 lenguajes, autocompletado, búsqueda y reemplazo con expresiones regulares, edición de múltiples documentos en pestañas, macros y soporte de plugins. La edición de imágenes (formatos PNG, JPG, etc.) requiere herramientas específicas como GIMP o Photoshop.
